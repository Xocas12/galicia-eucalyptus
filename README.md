# galicia-eucalyptus

Machine learning and geospatial intelligence to measure what eucalyptus plantations in Galicia do
to **native forest**, **wildfire** and **water**. The research design, estimands, data inventory
and threats to validity are in [`docs/SCOPE.md`](docs/SCOPE.md).

> Self-contained subproject. It shares nothing with `gosplan/` at the repository root: it has its
> own `pyproject.toml`, tests and virtual environment.

**Status: skeleton.** Module layout and scope only; the implementation follows.
